# Formal Word report format

Use this reference only when producing or revising the formal `.docx` report. `assets/pimax-country-market-report-template.docx` is the approved final Germany V3 and controls both content structure and visual format. Read [germany-v3-canonical.md](germany-v3-canonical.md), duplicate the master, and replace it section by section. Do not clear the body and independently redesign the report. Replace all country-specific evidence, wording, examples and sources; the master is not a research source.

## Visual system

- A4 portrait, approximately 20 mm margins, one consistent section unless a genuinely necessary landscape table requires a separate section.
- Arial-compatible Latin and CJK typography. Use dark navy `#203E66` for hierarchy, table headers, evidence tags and rules.
- Cover: report title, competitor and action-plan subtitle, version/date, scope, weighting, internal-data coverage and evidence-label legend. Do not turn the cover into a summary page.
- Footer: report identity plus automatic page number. Avoid recurring headers unless the user requests them.
- Major headings must be numbered and immediately recognizable. Separate the report into `研究（50%）` and `执行（50%）`, then use numbered chapters and subsections.
- Use inline evidence tags such as `【公开✓】`, `【数据】`, `【推断】`, `【建议】`, `【待核验】` and `【风险】`. Do not use fluorescent highlighter blocks.
- Tables use a navy header with white text, light borders and alternating white/pale gray-blue rows. Repeat header rows across pages and prevent row splitting when practical.

## Information design

- Put core conclusions near the beginning, followed by the complete research and execution argument. Do not create a detached “领导速读页” unless explicitly requested.
- Use prose for interpretation and causality. Use tables only when comparing the same fields across competitors, channels, audiences, products, events or actions.
- Keep the comparison chain together: competitor action → evidence/result → Pimax state → gap → Pimax action → KPI/validation. Do not scatter these six elements across unrelated tables.
- Keep source and evidence limitations visible near the related conclusion. Do not hide all caveats in the appendix.
- Use a compact, clickable source appendix. A two-column source index is preferred when it prevents multiple sparse pages.
- Avoid forced page breaks that create empty or mostly empty continuation pages. A major section may begin mid-page when the heading provides a clear visual separator.

## Required navigation

The reader must be able to find these areas at a glance:

1. Core conclusions and decisions.
2. Country market status.
3. Meta Quest 3 and Valve Steam Frame teardowns.
4. Integrated competitor-to-Pimax comparison.
5. Pimax internal operations and data diagnosis.
6. Local-language keywords and discussion evidence.
7. Strategy and product priorities.
8. Audience and platform execution.
9. Content, Ads, communities, KOL, retail/ecommerce, B2B and exhibitions.
10. 30-day, 90-day and 6-month roadmap.
11. Measurement, risks, missing data and sources.

## Delivery checks

Before delivery:

- Render every page and inspect it visually at readable scale.
- Confirm there are no blank pages, clipped text, split headers, unreadable tables, orphan headings or a source appendix consisting mainly of raw URLs.
- Confirm page numbers update and the file opens as a Word document.
- Run section and accessibility checks when the document workflow provides them. Resolve high and medium findings; explain any intentional residual finding.
- Confirm all hyperlinks remain clickable and the report contains no claims copied from the template country.
- Compare the final heading outline and table purposes against [germany-v3-canonical.md](germany-v3-canonical.md). The report fails if it adopts only the Germany V3 colors or fonts while changing its content structure.
- Search the final DOCX package for Germany-specific country names, German-language ad copy, retailers, events, values and source titles. Remove every unintended carryover.
