# Final Germany V3 canonical structure

This reference is mandatory for every formal country Word report. The design and content-structure authority is:

`assets/pimax-country-market-report-template.docx`

It is byte-identical to the approved final file `Pimax_德国市场调研与执行方案_V3_2026-11.docx` at the time this standard was locked. Treat it as a master to adapt, not a source of country facts.

## Required chapter order

1. `0. 核心结论`
   - Core market judgment.
   - Primary growth constraint.
   - 90-day growth hypothesis.
2. `0.1 需要特别注意的六个数据点`
   - Use six decision-critical country data points. If more are essential, keep the first six as the highlighted set and discuss the rest later.
3. `0.2 管理层需要批准的四项决定`
   - Product resource allocation.
   - Scale prerequisites.
   - Channel or operating governance.
   - Execution cycle or other country-critical approval.
4. `报告结构与证据口径`
   - Explain fact, internal data, inference, recommendation, risk and missing evidence.
   - Show the 50% research / 50% execution structure.
5. `第一部分 研究（占50%）`

## Required table purposes

Preserve these purposes and comparable depth. Wording and row counts may change only to fit real country evidence.

1. Six critical data points: `注意事项 | 报告中的证据 | 管理含义`.
2. Report structure: `部分 | 领导要回答的问题 | 主要输出`.
3. Meta Quest 3 seven-step register: `渠道与动作 | 竞品动作 证据与可能作用 | Pimax覆盖与差距 | Pimax具体补法 | 验证与KPI`.

## Adaptation method

1. Duplicate the master file into the task workspace.
2. Inventory all headings, paragraphs and tables before editing.
3. Map target-country evidence to every canonical section and table purpose.
4. Replace the master section by section while retaining its styles, numbering hierarchy, table treatment, header/footer and content density.
5. Where evidence is unavailable, keep the section and state the checked scope, limitation, validation action and owner; never remove the section.
6. Search the final package for `德国`, `德国市场`, German-language test copy, German events, German retailers and Germany-specific values. Only intentional comparative mentions may remain and must be labeled.
7. Compare the final heading outline and table-purpose checklist to this reference before rendering.

## Visual parity acceptance

- The reader should recognize the new country report as another edition of the Germany V3 series.
- Preserve the cover information types, numbered hierarchy, evidence tags, navy table system, highlight treatment, paragraph-to-table balance, source appendix density and footer/page-number behavior.
- Do not clear the document body and apply an independently designed report system.
- Do not compress the report into fewer high-density tables or replace connected analysis with card fragments.
- The goal is structural and visual parity, not identical page count. Page count may change because local evidence and language length differ.
